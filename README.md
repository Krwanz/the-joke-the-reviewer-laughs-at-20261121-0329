## How it works

`entry.txt` holds the joke (156 characters, one line). `main.ts` copies it to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. Run it locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
